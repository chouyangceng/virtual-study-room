# 虚拟自习室使用说明

这是一个纯前端的虚拟自习室网页，打开后就能直接使用。它把番茄钟、白噪音、任务管理、计划导入、学科管理、课表分析、复盘总结和专注统计放在同一个页面里，适合考研、自学、课程安排和日常学习监督。

网页可以部署到 HTTPS 后安装到 Android 主屏幕或 Windows 桌面。顶部按钮现在同时显示图标和中文名称，手机和电脑都能操作。

### 设备同步

点击顶部“设备同步”按钮，在安卓端选择“导出安卓数据”，把生成的 JSON 文件通过微信、网盘或数据线传到 Windows，再在 Windows 端选择“导入到本机”。导入前会提示覆盖当前浏览器数据。

当前版本是安全的手动同步，因为纯静态网页没有服务器，不能自动实时同步。导出的备份文件现在带有 `schemaVersion`，以后如果数据结构升级，导入时会先做版本提示，再继续兼容导入。若要多设备实时同步，需要接入 Supabase、Firebase 或自建 API。

详细步骤和快捷键见 `docs/设备同步快速说明.md`。Windows 上还可以用 `Ctrl + Shift + I` 快速打开导入窗口，用 `Ctrl + Shift + E` 快速导出数据。

## 一、先怎么打开

你可以直接打开仓库里的 `index.html`，也可以打开打包好的 `虚拟自习室.html`。如果你想让背景图、统计图和部分资源加载更稳定，推荐用本地服务器运行。

例如：

```bash
python3 -m http.server 8080
```

然后在浏览器访问 `http://localhost:8080`。

## 二、这个网页能做什么

### 1. 番茄钟和专注计时

页面中央是主计时器，可以选择常用学习模式，比如 25+5、45+10、50+10，也可以自定义工作和休息时长。

它不只是简单倒计时，还会记录真实专注时长：

- 切换到后台时会做时间校正
- 暂停时间不会算进专注总时长
- 可以查看累计专注、今日专注、连续天数等数据

### 2. 白噪音和背景音乐

网页内置了白噪音和轻音乐，不需要额外下载音频文件。

可选内容包括：

- 白噪音：雨声、咖啡馆、壁炉、海浪、森林等
- 轻音乐：适合学习的轻柔背景音

你可以一边学习一边开着低音量环境音，减少空白环境带来的干扰。

### 3. 风光背景

背景会显示自然风光照片，整体更安静，也更适合长时间盯着屏幕。

如果网络不稳定，页面会自动切换为备用背景，不影响基本使用。

### 4. 全景专注模式

如果你想把风景背景真正用起来，可以点击顶部的 `◉` 按钮进入全景专注模式。

进入后会隐藏任务、统计、课表等工作区，只保留大背景、居中的倒计时和最小化的开始/暂停控制。适合已经安排好任务、准备进入一段连续专注时使用。

- 点击右上角“退出全景”返回完整工作台
- 也可以按 `Esc` 退出
- 全景模式不会清除或暂停当前任务、音频和计时状态

### 5. 任务清单

你可以随时新增任务，完成后勾选，支持删除、清空和整理。

任务不只是待办清单，还能和专注时间、复盘内容联动，方便你知道自己到底做完了什么。

系统把每天早上 7 点作为新学习日的起点，所以凌晨到 7 点之间的记录会算到前一天。

任务支持多级分类和标签。分类路径用 `/` 分级，例如 `考研/数学/高数`；标签用逗号分隔，例如 `重点,真题,错题`。任务面板下方可以按分类筛选，选择上级路径时会包含其下级分类。

### 5. 计划导入

这是这个版本最重要的功能之一。

你可以把桌面上的学习计划表直接导入进来，支持：

- 每日计划
- 每周计划
- 每月计划
- 阅读计划
- 资料清单
- 其他按表格整理的计划内容

导入后，系统会自动把计划拆成当天任务、周任务或月任务，并尽量识别：

- 什么时候做
- 做多久
- 属于哪个学科
- 是否属于阅读或资料类内容

顶部“📥”按钮可以打开统一导入窗口。选择完整 Excel 模板后，可勾选计划、学科目标和课表，一次写入对应板块。计划列表中的每条记录都可以单独删除；已导入的整张表也可以整体删除。每周计划会在主页面右侧“本周计划”卡片中直接显示。

### 6. 学科中心

你可以给每个学科单独建目标，比如：

- 英语
- 数学
- 政治
- 专业课
- 自定义学科

每个学科都可以设置：

- 目标内容
- 每日任务量
- 每日学习分钟数
- 计划时间段
- 完成进度

这对考研监督特别有用，因为你能把“总目标”拆到“每天要完成多少”。

### 7. 课表导入和空闲时间分析

你可以导入学校教学管理系统导出的课表文件，系统会自动识别课程安排，按周展示哪些时间已经被课程占用，哪些时间还能学习。

这样你就能直接看到自己的空闲时间，更适合安排考研复习、阅读和刷题。

### 8. 48 格时间规划

页面里有一天 48 个半小时格子。

你可以用类似拖动选择的方式，把某个时间段分配给某个任务。这样做的好处是：

- 日程更直观
- 不会只停留在“有任务”，还能知道“什么时候做”
- 可以避免时间撞车

### 9. 每日复盘和一天结束总结

每个任务完成后都可以写一个小复盘，比如：

- 今天做了什么
- 难点是什么
- 完成质量如何
- 下一步怎么改

当一天的最后一个任务完成后，页面会弹出整日总结，你可以填写：

- 今日总体复盘
- 明天未完成任务清单

系统会把所有小复盘汇总成一份更完整的日报。

如果你写错了某条复盘，也可以在“每日复盘”里重新编辑或删除；未填写的任务会单独显示成待复盘，方便你集中补齐。

每日复盘摘要还会按学科显示“已复盘/已完成任务”比例；导出 Markdown 时也会保留这部分数据，能直接看出哪一科完成了任务却没有形成复盘闭环。

### 10. DeepSeek API 接入

如果你填写了 DeepSeek 兼容接口信息，系统可以把每日复盘内容交给模型点评和分析。

这个点评模式偏严格，会尽量指出：

- 目标是否模糊
- 计划是否空泛
- 哪些地方没有真正落实
- 明天该怎么改

它适合做学习监督，不适合拿来写漂亮话。

### 11. 数据导出和备份

在“专注统计”里点击导出后，会得到更完整的本地数据备份，内容包括：

- 专注记录和专注活跃数据
- 学习计划、学科、课表和目标
- 每日复盘、每日收尾和界面/音频设置

如果你想换电脑，先导出这份文件最稳妥。

### 12. 专注统计和分析

页面还会帮你整理专注数据，比如：

- 今日专注时长
- 今日次数
- 平均单次时长
- 最长单次时长
- 连续学习天数
- 最近 7 天趋势
- 周/月统计图
- 热力图

你可以用这些数据判断自己是不是在“假努力”，还是已经形成了稳定节奏。

## 三、怎么使用

### 1. 开始一次专注

先添加一个任务，然后点击开始即可。

学习过程中你可以：

- 切换白噪音或背景音乐
- 调整音量
- 查看今日任务
- 参考今日时间轴安排下一步

### 2. 导入学习计划

点击顶部的导入按钮，选择你的 Excel、CSV 或 TSV 文件。

导入时系统会先预览内容，确认后再真正写入。

适合导入的内容包括：

- 暑假学习计划
- 考研周计划
- 每月安排
- 阅读计划
- 资料整理表

### 3. 导入后怎么整理

导入完成后，建议你按这个顺序检查：

1. 先看是否识别成了每日、每周或每月计划
2. 再看学科有没有分对
3. 然后看开始时间和时长有没有自动识别出来
4. 最后到 48 格时间规划里补齐细节

### 4. 删除整个计划表

如果你导入错了，不需要一条一条删。

你可以直接删除整张导入表，这样这一批计划和它生成的任务会一起清掉，重新导入更方便。

### 5. 课表导入

如果你有武汉理工大学教学管理系统导出的课表文件，直接导入即可。

导入后可以看到：

- 哪些时间上课
- 哪些时间空闲
- 哪些周次有课
- 哪些时段适合安排复习

### 6. 写复盘

每完成一个任务，建议顺手写一句复盘。

短一点也可以，比如：

- “完成了，但效率一般，明天换更早的时段。”
- “今天数学卡住了，先回到例题。”
- “阅读完成，整理还没做，明天补。”

这样最后汇总出来的日报会更真实。

## 四、模板怎么用

页面已经提供了可下载的 Excel 模板。

你可以先下载模板，再按模板格式填内容，然后重新导入。

模板主要分三类：

- 计划导入模板
- 学科目标模板
- 课表导入模板

如果你手上是杂乱的计划表，建议先整理成模板格式再导入，成功率会高很多。

## 五、数据保存在哪里

所有数据默认保存在浏览器本地，不会自动上传服务器。

这包括：

- 任务
- 计划
- 学科
- 课表解析结果
- 专注记录
- 复盘内容
- 页面设置

如果你清理浏览器缓存或站点数据，本地内容也会一起消失，所以建议定期导出备份。

## 六、适合什么人

这个版本尤其适合：

- 考研党
- 暑假冲刺党
- 需要课表和计划一起管理的人
- 想用复盘提升执行力的人
- 不想只看待办列表，而是想看时间安排的人

## 七、常见问题

### 1. 为什么我导入后没有显示每日计划

通常是因为表格格式和模板差太多，或者列名不够明确。

解决办法：

- 优先用下载好的模板
- 把“日期、周次、星期、开始时间、时长、学科”这些信息补完整
- 重新导入

### 2. 为什么课表识别不完整

大多数时候是文件格式和教学系统导出格式不一致。

建议直接使用系统导出的原始 Excel，不要改列名，也不要随手合并单元格。

### 3. 为什么白噪音没声音

先检查浏览器是否允许音频播放，再看音量是不是被调到 0。

### 4. 为什么统计图不显示

如果你是离线打开，图表依赖的外部资源可能加载失败。

这时建议用本地服务器打开。

## 八、推荐用法

如果你想把它真正用成一个考研监督工具，我建议按这个节奏：

1. 先导入总计划
2. 再导入学科目标
3. 再导入课表
4. 用 48 格把空闲时间分配出去
5. 每完成一个任务顺手复盘
6. 晚上用整日总结收尾

这样它就不只是“一个自习室页面”，而是一个能帮你盯住执行的学习系统。
