# 虚拟自习室 1.3.0 使用说明

## 每日任务

左侧“每日任务”是整个应用唯一的任务入口。

1. 选择“今日任务”或“每日坚持”。
2. 填写任务名称；分类和标签可选。
3. 点击添加或按 Enter。
4. 完成后点击任务左侧圆形勾选按钮。

“今日任务”只在当天显示。“每日坚持”每天早上 8 点刷新为未完成，历史打卡不会被清除，任务卡会显示当前连续坚持天数。

## 番茄钟

番茄钟顶部的任务选择器直接读取左侧未完成任务。请先新建任务，再选择任务并开始专注。每完成一次，任务会累计番茄数和专注分钟。

首次开始计时时，系统可能询问通知权限。允许后，专注或休息结束会发送系统通知。应用不会触发振动。

## 周计划与月计划

顶部日历按钮打开计划中心。新版只保留：

- 周计划
- 月计划

今日安排全部进入每日任务，不再在计划中心重复显示。导入 Excel 时，“今日任务”和“每日坚持”行会自动进入每日任务；“周计划”和“月计划”进入计划中心。

删除整张导入表时，同一来源的每日任务和周/月计划会一起删除，避免界面删掉后数据仍残留。

## 多目标倒计时

点击顶部目标按钮或右侧目标卡的“管理”，可以连续添加多个目标。右侧卡片会同时显示所有目标；点击任一目标可进入编辑。

## 全景与全屏

全景模式只保留计时圆环、数字和必要控制。新版已限制数字宽度并单独分层，避免数字与圆环互相覆盖。按 Esc 或“退出全景”返回。

## 导出与同步

统计窗口可导出 JSON。设备同步仍以 Windows 归档服务为权威端。新版同步内容包括任务、周/月计划、课表、多目标、番茄记录、复盘和应用设置。

旧学科、旧音频字段不再写入新版导出和同步。

## 学习档案与复盘中心

顶部复盘按钮打开完整学习档案：

- “今日整合”按任务组合今天的每一次计时、单次复盘和任务完成复盘。
- “每日档案”用日历查阅过去每一天的计时、任务复盘、每日总结和 AI 点评；未来日期仍可安排待办。
- “每周报告”按周汇总专注时间、计时次数、完成任务、复盘内容和下一步行动，可以保存或下载 Markdown。

连接 Windows 数据中心后，顶部会显示参与汇总的设备。其他设备上传的内容为只读归档，避免在 Windows 查看时误删原设备记录。

## DeepSeek 周报

在“每周报告”右侧填写接口地址、模型和 API Key。默认支持 `deepseek-chat` 与 `deepseek-reasoner`。先生成事实周报，再点击“DeepSeek 深度总结”。

API Key 仅保存在当前浏览器或应用本地，不进入备份或同步；周报正文会随下一次同步进入 Windows 归档。建议使用有余额上限的 Key，并优先使用 HTTPS 接口。

## 数据安全

- 数据主要保存在本机，请定期导出备份。
- 早上 8 点是学习日切换边界。
- 升级不会强制删除旧历史字段；不再使用的旧数据只会被忽略。
