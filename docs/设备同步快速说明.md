# 设备同步快速说明（1.4.0）

Windows 版继续作为权威归档端。其他设备上传快照，只有 Windows 已持久化并返回有效回执后，客户端才允许清理已确认归档的旧历史。

## 最简单的连接方式

1. Windows 打开“同步与备份”，保持自习室或后台归档任务运行，记下局域网服务地址和同步 token。
2. Mac、Android、平板或手机连接到能访问该 Windows 的网络。
3. 在其他设备的“同步与备份”中填写服务地址和 token，设备名称保持默认即可。
4. 点击“测试连接”，成功后点击“立即上传”。以后应用打开、回到前台、联网及定时间隔都会自动上传。

Windows 的复盘中心会读取全部不可变快照，按记录 ID 去重并整合各设备的计时、单次复盘、任务复盘、每日总结和周报。客户端只有拿到与上传内容哈希一致的持久化回执后，才会按保留天数清理旧历史。

新版归档字段包括：

- 番茄记录和每日统计
- 统一任务与每日坚持历史
- 周计划、月计划
- 课表
- 多目标倒计时
- 每日复盘、收尾记录
- 每周报告
- 计时器和应用设置

白噪音/音频设置、学科目标和当前学科不再同步。旧归档可以继续读取，未被新版采用的字段会被忽略。

手工 JSON 导入会覆盖同名本地字段，导入前请先导出当前数据。同步 token 和 API Key 不会写入导出文件。

DeepSeek API Key 永远不会上传到 Windows；只同步生成后的复盘或周报正文。若测试连接失败，请确认 Windows 防火墙允许局域网访问 TCP 43110，且两台设备之间没有访客网络隔离。

## Android

Android 版与 Windows/Mac 使用完全相同的任务、计时、复盘、周报、统计和目标页面。首次安装后进入“同步与备份”，填写 Windows 的局域网地址（例如 `http://192.168.3.152:43110`）和 token。Android 应用回到前台、网络恢复或达到同步间隔时会自动上传；Android 系统彻底停止应用后不会在后台强行唤醒。
