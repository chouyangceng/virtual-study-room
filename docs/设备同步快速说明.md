# 手机 / 平板 / macOS → Windows 自动归档快速说明

## 现在的数据方向

手机、平板和 Mac 都是离线优先客户端；Windows 是长期保存终端。当前协议是“每台客户端把完整快照单向归档到 Windows”，不是多端实时共同编辑，也不会假装自动解决任务冲突。

每次上传会按设备生成不可变 JSON 文件。Windows 原子落盘并重新计算 SHA-256 后才返回 durable receipt；只有客户端验证回执与本次上传字节完全一致，才允许执行保留期清理。Windows 归档不会被定期清理。

## 第一次设置

1. 在 Windows 源码目录运行 `npm run archive:win`，或启动 Windows Electron 软件。
2. Windows 本机打开 `http://localhost:43110`，进入“设备同步”。
3. 记下页面显示的局域网地址和同步 token。token 仅回环本机可读取。
4. 手机 / 平板打开局域网地址；Mac 软件打开“设备同步”。
5. 填写 Windows 服务地址与 token，为设备命名，点击“测试连接”。
6. 点击“立即上传”。看到“Windows 已持久化归档 …”后才代表完成。

默认设置：每 15 分钟尝试上传，本地历史保留 30 天，确认归档后自动清理。可以关闭自动同步或自动清理。失败不会阻塞计时、任务与复盘，会在联网、回到前台或下一定时点重试并退避。

## 手机 / iPad 安装说明

- `http://局域网IP:43110`：可直接学习和同步，但普通 LAN HTTP 不是安全上下文，不能保证安装 PWA 或离线重开。
- 受信任 `https://`：可以安装到主屏幕并启用 Service Worker 离线应用壳。需要你自己的受信任 HTTPS 反向代理、域名证书或 Tailscale HTTPS。
- iOS/Android 把页面完全关闭后不会在后台定时同步；重新打开、联网或回到前台时会补传。
- 不要关闭浏览器隐私模式后期待数据保留，也不要手动清除站点数据。

## macOS 软件

- Apple Silicon：`npm run dist:mac:arm64`
- Intel：`npm run dist:mac:x64`
- Mac 端不会启动归档服务；需要填写 Windows 局域网地址和 token。
- 未签名构建只适合个人测试。正式分发需 Apple Developer 签名与公证。

## 恢复 Windows 归档

1. 点击“刷新列表”。
2. 可先“下载”并验证归档。
3. 点击“恢复”时会再次校验 SHA-256。
4. 页面会先触发当前本机安全备份下载，并要求第二次确认后才覆盖本地学习数据。

同步 token 与 DeepSeek API Key 不随恢复覆盖，也不会进入归档。

## 客户端清理边界

只清理以下超过本地保留期的历史：

- `focusSessions`
- `dailyReviews`
- `dailyCloseEntries`

记录必须已经包含在获得 durable receipt 的那一份快照中，而且上传后内容没有被编辑。未完成任务、计划、课程、学科、目标、偏好、API Key 和 token 永不由自动清理删除。每天最多自动清理一次。

## Windows 数据与配置

- 默认数据目录：`%USERPROFILE%\Documents\虚拟自习室数据`
- 端口：`43110`
- 配置环境变量：`VSR_ARCHIVE_PORT`、`VSR_ARCHIVE_DATA_DIR`、`VSR_ARCHIVE_HOST`
- `service-config.json` 保存随机 token；不要加入 Git 或发送给不可信人员。
- 局域网访问失败时，检查 Windows 防火墙是否允许 Node/Electron 的专用网络入站连接。

## 手工 JSON 仍然可用

## 最快方式

1. 在安卓打开虚拟自习室，点击顶部“设备同步”按钮。
2. 点击“导出安卓数据”，得到一个 `focus-data-日期.json` 文件。
3. 用微信文件传输、网盘、USB 数据线或邮件把 JSON 文件传到 Windows。
4. 在 Windows 打开虚拟自习室，点击“设备同步”→“导入到本机”。
5. 选择刚才的 JSON 文件，确认覆盖本机数据，页面会自动刷新。

## 快捷键

- Windows / 外接键盘：`Ctrl + Shift + I` 直接打开导入窗口。
- Windows / 外接键盘：`Ctrl + Shift + E` 直接导出当前完整数据。
- 手机触屏没有物理快捷键，使用顶部“设备同步”按钮即可。

## 导入包含什么

任务、学习计划、学科目标、课表、多个目标、番茄钟记录、复盘、每日收尾、主题和音频设置都会写入备份。

## 手工导入注意事项

- 导入会覆盖当前浏览器中的本地数据，导入前请确认文件正确。
- 手工导入是覆盖式恢复，不是数据合并；导入前应先导出本机备份。
- 导出文件不会包含 DeepSeek API Key 或同步 token；导入也不会覆盖当前 API Key。
- 要安装到安卓或 Windows，需要用 HTTPS 地址打开；直接双击 `file://` 文件只能使用网页，不能安装 PWA。
