# Excel 模板导入说明

## 完整模板

点击顶部“下载 Excel 模板”，会下载 `虚拟自习室-一键导入模板.xlsx`。模板包含三个工作表：

- 计划导入模板：任务内容、详细说明、类型、日期、周次、星期、月份、开始时间、时长分钟、学科、分类路径、标签
- 学科目标模板：学科名称、目标 / 截止日期、每日任务量、每日学习分钟、时间安排、颜色、备注
- 武汉理工课表模板：课程名称、课程号/班号、教师、星期、节次、开始时间、结束时间、起始周、结束周、教室、备注

## 一键导入

点击顶部“📥 一键导入完整模板”，选择 Excel 后勾选需要导入的板块，再点击“导入勾选内容”。

计划类型可填写：`daily`、`weekly`、`monthly`、`reading`，也可以填写“每日”“每周”“月度”“阅读”。

## 导入后检查

1. 计划窗口检查每日、每周、本月、阅读四个页签。
2. 主页面右侧检查“本周计划”卡片。
3. 学科中心检查目标和每日分钟数。
4. 课表中心检查周次、星期和空闲时间。
5. 如果导入错误，可删除单条计划或删除整张导入表后重新导入。

## 成功率建议

- 第一行使用模板表头，不要合并单元格。
- 日期写成 `2026-08-09`，开始时间写成 `09:00`，时长写数字分钟。
- 每周计划至少填写“任务内容”和“类型”。
- 分类路径用 `/` 分层，例如 `考研/数学/高数`；标签用逗号分隔，例如 `重点,真题,错题`。
- 课表尽量使用教学管理系统导出的原始文件。
