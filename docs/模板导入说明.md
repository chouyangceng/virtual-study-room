# 1.2.0 模板导入说明

顶部下载按钮会生成一个 Excel，包含：

- `任务与计划模板`
- `课表模板`

任务与计划表建议字段：任务内容、详细说明、类型、日期、周次、星期、月份、分类路径、标签。

`类型` 支持：

- 今日任务：导入每日任务，仅在指定日期显示；日期为空时使用当前学习日。
- 每日坚持：导入每天重复打卡的任务，早上 8 点刷新。
- 周计划：进入周计划。
- 月计划：进入月计划。

旧模板中的“每日”按今日任务处理；含“固定、习惯、每日坚持”的类型按每日坚持处理。阅读计划和学科目标不再导入。

导入前会显示周计划、月计划数量，并提示将进入每日任务的条数。再次导入同一文件时会按来源、类型、日期和任务名去重。
