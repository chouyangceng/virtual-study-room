# 虚拟自习室项目问题清单

日期：2026-08-09

这是对当前项目做的一次问题归档。重点不是继续堆功能，而是把已经开始变脆的地方先收住。

## 1. 数据字段开始重叠

现在任务、计划、学科之间有不少近义字段：

- `subjectId`
- `subject`
- `subjectName`
- `category`
- `categoryPath`
- `tags`

这会导致统计、筛选、导入时需要多重兜底，短期能用，长期会越来越难维护。

## 2. 备份还是覆盖式导入

虽然已经加了 `schemaVersion`，但当前导入逻辑本质上还是整包写入本机。

风险：

- 旧数据和新数据不好合并
- 冲突时没有用户选择
- 以后字段一多，迁移会很麻烦

## 3. 离线能力不够硬

统计图和 Excel 仍依赖 CDN：

- Chart.js
- SheetJS

网络不好时，图表和导入会受影响。纯本地桌面使用时，这个问题会更明显。

## 4. 功能入口已经偏多

现在页面已经不是“一个番茄钟网页”，而是一个学习操作台。

这意味着后续再加按钮，可能会带来：

- 找功能更难
- 面板更挤
- 同类能力重复出现

## 5. 单文件版必须和源码版一致

单文件版一旦漏掉主模块，就会出现“源码能用，桌面单文件缺功能”的问题。

重点模块包括：

- `import-hub`
- `sync`
- `reviews`
- `stats`

## 下一步建议

1. 先统一数据 schema，减少近义字段。
2. 做“保存视图”和“标签分析”，替代继续加新入口。
3. 把备份升级成“可合并 + 可选择冲突处理”。
4. 离线化图表和 Excel 依赖。
5. 单文件版继续保持和模块版同步，不要让两份代码再分叉。
