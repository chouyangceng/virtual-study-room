# 📚 虚拟自习室 Virtual Study Room

沉浸式在线自习室，单文件纯前端应用，打开即用。

## 功能

- 🍅 **番茄钟** — 25+5 / 45+10 / 50+10 / 自定义，SVG环形进度，自动切换工作/休息
- 🖼️ **高清背景** — Unsplash精选图片自动轮换，5套渐变备选
- 🎵 **白噪音/轻音乐** — 6种白噪音 + 3种轻音乐，Web Audio API合成，无需音频文件
- 📋 **任务清单** — 添加/完成/删除，批量导入（粘贴多行一键导入）
- 📊 **专注统计** — 本周柱状图、月度趋势图、GitHub风格热力图，JSON导出
- 🏆 **成就系统** — 17枚徽章（专注次数、连续天数、时长积累、早起鸟/夜猫子）
- 📅 **月度目标日历** — 为每天设定学习目标，一览整月安排
- 🌓 **深色/浅色主题** — CSS变量驱动，一键切换
- ⌨️ **快捷键** — 空格=开始/暂停，R=重置

## 使用方式

### 方式一：直接打开（推荐）
下载 `虚拟自习室.html`，双击用浏览器打开即可。可发送到任何设备使用。

### 方式二：本地服务器
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 技术栈

- HTML5 / CSS3 / Vanilla JS
- Chart.js (CDN) — 统计图表
- Web Audio API — 白噪音与音乐合成
- Unsplash — 背景图片
- localStorage — 数据持久化
