# 📚 虚拟自习室 Virtual Study Room

沉浸式在线自习室，打开浏览器就能使用。它把番茄钟、任务清单、环境音和专注数据放在同一个安静的工作台里，适合个人学习、阅读和远程办公。

## 功能

- 🍅 **番茄钟** — 25+5 / 45+10 / 50+10 / 自定义，SVG环形进度，自动切换工作/休息
- ⏱️ **准确计时记录** — 基于时间戳校正后台切换和定时器漂移，暂停时间不会被计入专注时长
- 🖼️ **自然风光背景** — 山川、森林、海岸等 Unsplash 风光照片自动轮换，另有渐变备选
- ◉ **全景专注模式** — 隐藏工作区，只保留大背景、居中倒计时和最小控制，按 Esc 或右上角按钮退出
- 🎵 **白噪音/轻音乐** — 6种白噪音 + 3种轻音乐，Web Audio API合成，无需音频文件
- 📋 **任务清单** — 添加、完成、删除和清除已完成任务
- 📊 **专注分析** — 完成率、平均/最长时长、高效时段、近 7 日趋势、最佳专注日、周/月图表与热力图
- 📝 **每日复盘** — 每项任务完成后记录完成情况、难度、实际产出和下一步，自动汇总并导出 Markdown/JSON 日报
- 🌙 **每日收尾审查** — 最后一项任务完成后自动汇总小复盘，可填写整日复盘与明日未完成清单
- 🤖 **DeepSeek 严格点评** — 可选接入 OpenAI 兼容接口，识别模糊目标、借口与计划漏洞，生成可验收行动
- 📚 **学科中心** — 为政治、英语、数学、专业课或自定义学科设置目标、每日任务量、每日学习分钟和时间段，并按学科追踪完成率
- 📥 **多模板导入** — 计划、学科目标和武汉理工课表均支持 Excel 一键导入，并可直接下载对应模板
- 📅 **课表空闲时间** — 兼容教学管理系统导出的 `studentTimetable.xlsx`，按周次显示课程占用和可安排时段
- 🧭 **今日概览** — 实时显示今日次数、平均时长、连续天数与累计专注时间
- 📥 **一键导入学习计划** — 支持 `.xlsx`、`.xls`、`.csv`、`.tsv`，自动识别每日、每周、月度与阅读/资料计划，导入前可预览，数据仅保存在本地浏览器
- 🗂️ **计划中心** — 按今日、本周、本月、阅读和全部分类查看计划，并可逐项勾选完成
- 🕒 **计划时间规划** — 自动提取表格中的开始时间和分钟/小时，首页任务显示“什么时候做、做多久”；没有时长的内容会标记待补充
- 🧭 **今日时间轴** — 按开始时间展示当天日程，自动标记任务重叠和时间冲突
- 🧩 **48格时间分配** — 一天拆成 48 个半小时格，可拖动选择连续时间并分配给任意今日任务
- ↕️ **拖拽排序** — 在计划中心拖动任务调整执行顺序，首页今日任务同步更新
- ⏭️ **任务顺延** — 一键把当天所有未完成计划移动到明天
- 🗑️ **整表管理** — 查看每次导入的文件来源和数量，可一键删除整张计划表及其每日任务
- 📝 **专注历史** — 查看最近30条记录，支持单条删除和一键清空
- 🏆 **成就系统** — 17枚徽章（专注次数、连续天数、时长积累、早起鸟/夜猫子）
- 🌓 **深色/浅色主题** — CSS变量驱动，一键切换
- ⌨️ **快捷键** — 空格=开始/暂停，R=重置

## 使用方式

### 方式一：直接打开
双击 `index.html` 即可使用；也可以打开已打包的 `虚拟自习室.html`（单文件版，包含全部功能）。核心功能不需要后端，任务和记录保存在当前浏览器的 `localStorage` 中。

### 方式二：本地服务器（推荐，启用 PWA）
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

使用本地服务器时，Service Worker 会缓存页面资源，可离线使用并可安装为 PWA（添加到桌面/主屏幕，需要 HTTPS 或 localhost）；背景图片和 Chart.js 统计图正常加载。直接双击打开（file:// 协议）时没有网络则背景退回渐变、统计页显示文字提示、Excel 导入/图表库不可用，其余功能正常。

### 重新打包单文件版
修改 `index.html` / `css/` / `js/` 后，运行：
```bash
node tools/build-single-file.mjs
```
它会把所有 CSS 和 JS 内联进 `虚拟自习室.html`，保证单文件版与模块版一致。

### 导入计划表

点击顶部的 `🗓️` 或今日任务区的“导入”，选择 Excel/CSV 文件。导入器会优先识别带有“日期、星期、周次、阶段、今日主目标”等字段的每日计划，识别带有“周次、总目标”等字段的周计划，也支持“适用阶段、时间、任务、执行标准”形式的一日作息模板，并把“资料清单、书单、阅读计划”归入阅读分类。导入前可以预览分类数量；再次导入同名文件会替换上一次导入内容。

## 技术栈

- HTML5 / CSS3 / Vanilla JS
- Chart.js (CDN) — 统计图表
- SheetJS (CDN) — Excel/CSV 计划表解析
- Web Audio API — 白噪音与音乐合成
- Unsplash — 背景图片（仅加载图片，不上传学习数据）
- localStorage — 数据持久化

## 数据与隐私

所有学习记录、任务和偏好只保存在浏览器本地，不会发送到项目服务器。清除浏览器站点数据会同时清除这些记录；建议定期在“专注统计”中导出 JSON 备份。

## 发布到 GitHub Pages

这是一个纯静态站点，可在仓库 Settings → Pages 中选择 `Deploy from a branch`，分支选择 `main`、目录选择 `/ (root)`，保存后即可获得在线自习室地址。

## 项目结构

```
├── index.html               # 入口
├── 虚拟自习室.html          # 单文件打包版（由 tools/build-single-file.mjs 生成）
├── css/style.css            # 样式
├── js/
│   ├── storage.js           # localStorage 安全写入封装
│   ├── app.js               # 主控/成就/主题
│   ├── timer.js             # 番茄钟
│   ├── goals.js             # 多目标倒计时
│   ├── tasks.js             # 任务管理
│   ├── plans.js             # Excel/CSV 计划导入与计划中心
│   ├── import-hub.js        # 一键导入中心
│   ├── subjects.js          # 学科中心
│   ├── courses.js           # 课表与空闲时间
│   ├── reviews.js           # 逐项任务复盘与日报导出
│   ├── stats.js             # 统计图表
│   ├── sync.js              # 设备间 JSON 备份导入导出
│   ├── templates.js         # Excel 模板下载
│   ├── audio.js             # 音频引擎
│   └── background.js        # 背景管理
├── sw.js                    # Service Worker（离线缓存）
├── manifest.webmanifest     # PWA 清单
├── icons/                   # PWA 图标
├── tools/                   # 打包脚本
└── docs/                    # 文档
```
