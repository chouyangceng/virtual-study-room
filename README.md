# 虚拟自习室 1.2.0

一个离线优先的学习任务、番茄钟、周/月计划、复盘与统计工具。Windows 轻量版复用系统 Edge 与 Node，浏览器和单文件版也可直接运行。

## 1.2.0 核心变化

- 每日任务与番茄钟使用同一个 `tasks` 数据源。番茄钟必须从未完成任务中选择，不再维护第二套任务文本。
- 每日任务分为“今日任务”和“每日坚持”。每日坚持在早上 8 点刷新当日打卡状态，并保留连续坚持天数。
- 一个任务会累计完成的番茄数和专注分钟。
- 目标倒计时支持同时创建、展示、编辑和删除多个目标。
- 计划中心只保留周计划和月计划；Excel 中的今日任务、每日坚持会进入每日任务列表。
- 删除白噪音、背景音乐、学科中心、学科目标导入及其导出字段。
- 计时结束发送系统通知并播放短提示音，不调用振动 API。
- 主按钮改用本地 Lucide SVG 子集，桌面离线状态也能正常显示。
- 全景模式重新约束圆环、数字和控制按钮的布局，避免重叠。
- 顶部操作区收拢为“复盘、全景、更多”三个入口，次要功能按学习管理、数据工具、显示与计时分组。
- 导入与模板合并为一个流程，最新版统一模板包含填写说明、任务/计划示例和课表示例。
- 复盘分三层：番茄钟结束自动弹单次复盘，勾选任务完成自动弹任务复盘；每日总结由用户主动进入复盘中心完成。单次与任务复盘可在复盘中心继续修改。
- 复盘中心新增过往复盘，可按日期浏览并搜索任务、问题、产出和下一步。
- 应用和桌面快捷方式使用“打开的书 + 专注光点”新图标。

## 数据与迁移

数据默认保存在浏览器/Electron 的本地存储中。升级时不会主动清空历史：

- 旧 `daily` 计划迁移为今日任务或每日坚持。
- 旧阅读计划会写入 `legacyPlansV110` 作为兼容备份，不再显示在新版计划中心。
- 旧学科和音频设置不会继续参与界面、同步或新导出，但不会在启动时强制删除。

学习日以本地时间早上 8 点为边界。

## 开发与验证

```bash
npm install
npm run check:js
npm test
npm run build:single
npm run dist:win
```

- `index.html`：模块化入口
- `虚拟自习室.html`：构建生成的单文件版本
- `js/tasks.js`：统一任务、每日坚持、番茄统计
- `js/timer.js`：番茄钟、提示音、系统通知
- `js/plans.js`：周/月计划与 Excel 导入
- `js/goals.js`：多目标倒计时
- `shared/archive-core.js`：跨设备归档核心

## 图标许可

按钮图标来自 [Lucide](https://lucide.dev/)，以本地 SVG 方式使用。许可见 `icons/LUCIDE-LICENSE.txt`。

本轮只构建 Windows 版；Mac 版按用户要求以后再同步。
